# EstudioHC-OMP (estudiohc-omp)

Repositório dedicado à integração, configuração e perfis de agentes do **OMP (*oh-my-pi*)** conectados ao **OmniRoute Gateway** e à suíte **EstudioHC-Memory-Suite**.

## ⚙️ Configurações Inclusas
- `config.yml`: Papéis de modelo (*modelRoles*) apontando para os combos inteligentes do OmniRoute (`auto/best-coding`, `auto/best-reasoning`, `auto/best-fast`, `auto/best-vision`) com fallback local para LM Studio.
- `models.yml`: Catálogo explícito de modelos e provedores OpenAI-compatíveis.

## 🚀 Uso
Copie a pasta `.omp/` para o diretório de configuração do seu ambiente OMP.
